# ФОРМА — мини-каталог товаров

Тестовое задание (middle): каталог одежды на React с тремя страницами — список товаров, карточка товара и корзина.

## Стек

- **React 19** + **Vite**
- **TanStack Router** — code-based routing, без кодогенерации
- **UnoCSS** — утилитарные стили и токены темы
- **JavaScript + JSDoc** — типы описаны комментариями
- **localStorage** — сохранение корзины и промокода

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
npm run lint
```

## Маршруты

| URL | Страница |
| --- | --- |
| `/` | Каталог |
| `/product/$productId` | Карточка товара |
| `/product/1?color=2&size=4` | Карточка с выбранным цветом и размером |
| `/cart` | Корзина |
| `*` | Страница не найдена |

## Что реализовано

### Каталог

- Карточки с изображением, названием, брендом, ценой «от» и цветами.
- Поиск по названию.
- Фильтр «В наличии»: есть хотя бы один цвет хотя бы с одним размером.
- Сортировка по минимальной цене среди цветов (по возрастанию / убыванию).
- Состояния загрузки (скелетоны), ошибки с повтором и пустой выдачи.
- Поиск, фильтр и сортировка хранятся в URL — ссылку можно сохранить и открыть заново.

### Карточка товара

- Галерея без сторонних библиотек: стрелки, миниатюры, счётчик изображений.
- Выбор цвета; при смене цвета подставляется первый доступный размер.
- Все размеры показаны отдельными кнопками, недоступные для выбранного цвета заблокированы.
- Добавление одной единицы за клик, подтверждение на кнопке и в счётчике шапки.
- Экран «Товар не найден» со ссылкой назад.
- Выбранные `color` и `size` сохраняются в URL и восстанавливаются при открытии ссылки.

### Корзина

- Позиции уникальны по связке `товар + цвет + размер`; повторное добавление увеличивает количество.
- Количество меняется от 1, позицию можно удалить.
- Показаны изображение, название, цвет, размер, цена, количество и сумма позиции; внизу — общая сумма.
- Корзина и промокод сохраняются в `localStorage` и восстанавливаются после перезагрузки.
- Некорректные или устаревшие данные из хранилища безопасно нормализуются и не ломают приложение.

### Промокоды

| Код | Скидка |
| --- | --- |
| `SALE10` | 10% от суммы товаров |
| `MINUS500` | 500 ₽, но не больше суммы товаров |

Регистр не важен. После применения скидка отображается отдельной строкой, код можно убрать.

## Работа с данными

- Товары, размеры и цены берутся только из `src/services/api.js`.
- Структура данных не менялась. В цвета добавлен только `hex` для отображения свотчей — это разрешено условием задания.
- Каталог загружается один раз в `CatalogProvider` и переиспользуется списком, карточкой и корзиной.

## Структура

```
src/
  services/api.js        исходное псевдо-API
  router.jsx             дерево маршрутов TanStack Router
  store/
    CatalogContext.jsx   загрузка каталога и справочника размеров
    CartContext.jsx      корзина, промокод, производные итоги
  lib/
    cart.js              уникальные ключи и обогащение позиций
    cart-storage.js      чтение, валидация и запись localStorage
    catalog.js           селекторы: наличие, минимальная цена, обложка
    promo.js             поиск и расчёт промокода
    search.js            валидация и сериализация search params
    format.js            цены и склонения
  components/            шапка, карточки, галерея, состояния, иконки
  pages/                 каталог, товар, корзина, 404
```
